# Licensing and provenance

PCB.OTF uses original vector engineering drawings. They are informed by public
technical terminology, service manuals, open hardware documentation, and generic
datasheet geometry. No vendor logo, certification mark, or proprietary diagram is
the canonical artwork.

Source code, ontology, metadata, SVG masters, and documentation are MIT. Generated
fonts are OFL-1.1; the inherited DejaVu Sans prose base retains its upstream
license. The project is not affiliated with USB-IF, PCI-SIG, JEDEC, VESA, SATA-IO,
or any hardware vendor.
