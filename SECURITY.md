# Security policy

PCB.OTF is a static font, metadata package, and static specimen site. Report
unsafe HTML handling, malicious SVG/font parsing behavior, dependency problems, or
workflow issues privately through the maintainer contact on the
[`LuckyMonkey/pcb.otf`](https://github.com/LuckyMonkey/pcb.otf) profile rather than
opening a public issue. Include a minimal reproduction and affected commit. 🛡️
