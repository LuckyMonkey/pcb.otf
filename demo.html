PCB.OTF / ILLUSTRATED PARTS CATALOG

A PCIe slot is an object that happens to have a glyph.

An open, searchable computer-parts catalog: semantic hardware objects, original technical vectors, and a font that can set them in running text.

Not Wingdings. Ordinary letters stay ordinary. Try :usb_c:, :pcie_x16_slot:, or :ddr4_dimm:; without PCB installed, the source remains readable.

These are high-resolution black-on-white vector studies using patent-sheet conventions: construction lines, section tones, reference geometry, and multiple views. Transparent interiors keep assemblies readable when layers overlap. They are not copied patent figures or vendor illustrations.
